# Discord.py CMWorld Embed loader

코믹월드 홈페이지의 행사정보를 주기적으로 확인하고, 변경되면 Discord 채널에 임베드로 전송합니다.

## 실행

1. 가상환경에서 의존성을 설치합니다.

```powershell
pip install -r requirements.txt
```

2. 프로젝트 폴더의 `.env`에 아래 값을 설정합니다.

```env
DISCORD_TOKEN=디스코드_봇_토큰
DISCORD_CHANNEL_ID=전송할_채널_ID
POLL_MINUTES=30
AUTO_MESSAGE_TIME=09:00,18:00
AUTO_MESSAGE_TEXT=예약해서 보낼 메시지
AUTO_MESSAGE_TEXTS={"09:00":"아침 예약 메시지","18:00":"저녁 예약 메시지"}
# 여러 채널은 쉼표로 구분합니다. 생략하면 기본 예약 채널 2곳으로 전송됩니다.
AUTO_MESSAGE_CHANNEL_IDS=1549321583384862730,1548640303337046138
```

`DISCORD_CHANNEL_ID`는 Discord 개발자 모드에서 채널을 우클릭해 복사할 수 있습니다. 봇에는 해당 채널의 `View Channel`과 `Send Messages` 권한이 필요합니다.

`AUTO_MESSAGE_TIME`은 한국 표준시(KST) 기준 `HH:MM` 형식의 하루 한 번 전송 시각입니다. `AUTO_MESSAGE_TEXTS`를 사용하면 시간별로 다른 메시지를 보낼 수 있습니다. 예약 메시지는 두 서버의 지정 채널로 각각 전송됩니다. `AUTO_MESSAGE_TEXTS`가 없으면 기존 `AUTO_MESSAGE_TEXT`가 모든 시간에 사용됩니다.

3. 봇을 실행합니다.

```powershell
python Index.py
```

첫 실행 후 행사정보가 변경될 때만 메시지가 전송되며, 마지막 응답의 해시는 `.event_cache.json`에 저장됩니다. 이 파일은 자동으로 생성되므로 Git에 올리지 않는 것을 권장합니다.

봇이 실행되면 다음 슬래시 명령어를 사용할 수 있습니다.

- `/코믹인포`: 가장 가까운 행사 1건을 표시합니다.
- `/코믹스케줄 count:1~10`: 원하는 개수의 행사 일정을 표시합니다.
- `/메뉴추가 menu:메뉴명`: 현재 서버에 점심 메뉴를 등록합니다.
- `/점메추`: 현재 서버에 등록된 메뉴 중 하나를 랜덤으로 추천합니다.
- `/랭킹 type:레벨`: 현재 서버의 레벨과 엘리프 랭킹을 표시합니다.
- `/랭킹 type:퀴즈랭킹`: 현재 서버에서 퀴즈 정답을 맞힌 문제 수 순위를 표시합니다.
- `/퀴즈`: 기본 문제 또는 서버에 등록된 문제 중 하나를 공개적으로 시작합니다.
- `/문제출제 문제:... 정답:... 힌트:...`: 문제를 문제 은행에 저장합니다. 이 명령어만으로는 문제를 시작하지 않으며, `/퀴즈`로 나중에 공개 출제할 수 있습니다.

퀴즈는 서버마다 한 문제씩 진행할 수 있으며, `/퀴즈`는 서버 전체에서 4시간마다 한 번만 시작할 수 있습니다. 쿨다운 중에는 남은 시간을 `<HOUR>시간 뒤에 퀴즈를 풀 수 있어요.` 형식으로 안내합니다. 정답자는 5~20엘리프를 받습니다. 참가자는 문제마다 정답을 3회 입력할 수 있고, 누군가 정답을 맞히거나 누구든 포기 버튼을 누르면 전체 풀이가 끝납니다. 힌트는 유저마다 1회 무료이며, 두 번째 힌트는 15엘리프를 사용해 10초간 본인에게만 표시됩니다. 잔액이 부족할 때 레벨은 차감되지 않습니다.

메뉴 데이터는 `menus.db` SQLite 파일에 서버별로 저장되며, 같은 서버에 같은 메뉴를 중복 등록할 수 없습니다.

명령어는 Discord 전역에 동기화되므로 봇이 들어가 있는 모든 서버에서 사용할 수 있습니다. Discord 전역 명령어의 반영에는 최대 약 1시간이 걸릴 수 있습니다.
